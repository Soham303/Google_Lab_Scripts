Lab Name: Getting Started with Cloud Shell and gcloud
Lab Code: GSP002
Script: gsp002.sh

==================================================
Run Instructions:
==================================================

1. Open Google Cloud Shell from your active lab session.

2. Run the script:
   bash gsp002.sh

   (Or pass your assigned lab zone directly):
   ZONE=us-central1-a bash gsp002.sh

3. The script will:
   - Configure gcloud compute region and zone
   - Create the VM instance `gcelab2`
   - Attach network tags `http-server` and `https-server`
   - Create firewall rule `default-allow-http` for incoming port 80 traffic

4. When the script prints "ALL DONE", return to the lab page and click "Check my progress" for all tasks.
