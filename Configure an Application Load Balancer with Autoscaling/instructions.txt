Lab Name: Configure an Application Load Balancer with Autoscaling
Lab Code: OCBL105
Script: ocbl105_v2.sh

==================================================
Run Instructions:
==================================================

1. Upload `ocbl105_v2.sh` to Google Cloud Shell.

2. Start a tmux session so the lab continues running even if Cloud Shell disconnects:
   tmux new -s lab

3. Run the script dynamically:

   Method A - Interactive (Prompted for your lab's assigned regions/zones, or press Enter for defaults):
   bash ocbl105_v2.sh 2>&1 | tee lab.log

   Method B - Environment Variables (Pre-set your lab's specific regions/zones inline):
   R1=us-east4 Z1=us-east4-b R2=asia-east1 ZS=us-east1-b bash ocbl105_v2.sh 2>&1 | tee lab.log

4. If Cloud Shell disconnects at any point, reopen Cloud Shell and reattach:
   tmux attach -t lab

5. When the terminal prints "ALL DONE", return to the lab page and click "Check my progress" on each task, then click "End Lab".
